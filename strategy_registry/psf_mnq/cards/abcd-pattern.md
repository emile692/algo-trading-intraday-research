## Description publiée

Simplest harmonic structure — measured move with Fibonacci symmetry.

- **Entrée annoncée** : Enter at D when CD = AB (1:1 measured move) or CD = 127.2% of BC. Confirmation via bullish/bearish rejection candle.
- **Sortie annoncée** : Target 38.2% then 61.8% retracement of AD. Stop beyond 141.4% BC extension.
